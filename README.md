# Browser Cleaner 6.0

Browser Cleaner is a powerful utility designed to clean up your browser data, remove duplicates, and debloat your system for optimal performance.

## Features

- **Browser Cleaning**: Efficiently remove cache, cookies, history, and other temporary data from major browsers.
- **System Debloat**: Remove unnecessary pre-installed applications and optimize system settings.
- **Duplicate Finder**: Scan and remove duplicate files to free up disk space.
- **Startup Management**: Manage applications that launch at system startup.

## Installation

1. Run the installer `Browser Cleaner Setup.exe`.
2. Follow the on-screen instructions.
3. Launch the application from the desktop shortcut or start menu.

## Usage

- **Clean**: Select the browsers and data types you want to clean and click "Clean".
- **Debloat**: Navigate to the Debloat section to remove unwanted apps.
- **Duplicates**: Use the Duplicate Finder to scan for and remove duplicate files.
